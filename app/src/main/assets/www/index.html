Gemini (Google AI Studio)

Cara mendapatkan API key (gratis)
  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Ketuk Create API key.
  3. Salin key yang muncul (diawali AIza), lalu tempel di kolom di atas.
  4. Ketuk Simpan & cek.

API key hanya tersimpan di HP ini. Jangan bagikan ke orang lain.
